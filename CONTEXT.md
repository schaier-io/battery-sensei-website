# Glossary

## Plan Names

- **Lifetime**: Canonical one-time plan name. Keep as visible label.
- **Yearly Patron**: Canonical recurring plan name. Replace legacy labels like "Yearly support" or "Ongoing Developer Support" in user-facing copy.

## License Scope

- **Lifetime unlock**: Up to 3 Macs owned by the buyer.
- **Yearly Patron scope**: Up to 5 Macs while subscription is active.
