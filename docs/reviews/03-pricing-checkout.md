# Pricing and checkout

## Scope and coverage

**Surface.** The money path. The `Pricing` section on the homepage and every localized homepage, and the `/checkout` route for both tiers.

**Files in scope (12).** `src/components/sections/Pricing.tsx`, `src/routes/checkout.tsx`, `src/components/PolarInlineCheckout.tsx`, `src/components/MacOnlyConfirm.tsx`, `src/components/zen/PriceDisplay.tsx`, `src/lib/pricing.ts`, `src/lib/use-price.ts`, `src/lib/use-discount-availability.ts`, `src/lib/use-polar-embed.ts`, `src/lib/polar.ts`, `src/lib/use-count-up.ts`, `src/routes/api/checkout.$id.ts`.

**Stack.** TanStack Start and Router, React 19.2.6, Tailwind v4, radix-ui, `motion`, react-i18next with five bundled locales. Colors come from CSS custom properties in `src/styles.css`. Components are hand-rolled against those tokens; the shadcn primitives in `src/components/ui/*` exist but this surface does not use them.

**Convention documents found.** `CONTEXT.md` (ubiquitous language), `PRODUCT.md` (register, design principles, accessibility bar). No `CONTRIBUTING.md`, `CODING_STANDARDS.md`, or design-system doc.

**Boundary.** Out of scope by instruction: Nav, Footer, the language and currency switchers, `/thanks/*`, `src/components/ui/*`. `NotOnMacBanner` renders inside `/checkout` but is not in the file list, so it was not reviewed. No browser was used; the orchestrator runs the rendered pass.

## Verification

### Checked and passed

- **Retired plan and tier names.** `python3` walk of `pricing`, `checkout`, `licenseScope`, `common` and `macOnly` in all five locale files against `/premium|yearly support|ongoing developer support|battery journal/i`. Zero user-facing hits. All five files use "Lifetime", "Yearly Patron" and "Pro" as `CONTEXT.md` requires. The retired terms survive only in code identifiers and in the dead module (L1). "battery history" is a separate retired label and is the subject of the first MEDIUM.
- **Recommended plan marked by more than color.** `Pricing.tsx:293-295` renders a text pill reading `t('common.recommended')`, translated in all five locales. The Lifetime card also carries `ring-1 ring-hinomaru/20` and a hinomaru-tinted tier label, but the word is present in the reading order, so the marking does not depend on color.
- **Scarcity is real, and there is no countdown.** `use-discount-availability.ts` contains no timer, no `Date`, and no deadline. `remaining` is `Math.max(0, json.max - json.used)` from `/api/discount-availability`, and `live: false` on any failure suppresses every scarcity surface. `Pricing.tsx:132-134` and `checkout.tsx:104-106` add a second gate on Polar reporting `original.amount > discounted.amount`, so a stale strikethrough cannot render.
- **`use-count-up` does not animate any price.** `grep -rn "useCountUp" src/` returns one call site, `src/components/zen/BatteryJournal.tsx:118`, which is out of scope. No price on this surface is animated. The hook itself checks `prefers-reduced-motion` at `:41-46` and sets the final value immediately when it matches, and the current value is React state, so the DOM always carries a real number rather than one reached only by animation.
- **Currency formatting uses `Intl.NumberFormat`.** `PriceDisplay.tsx:39-44` uses `formatToParts` and honours symbol position, the locale's literal gap and locale separators. `pricing.ts:118-152` uses `Intl.NumberFormat` throughout. The locale it is handed is the defect, not the API. See the fourth MEDIUM.
- **Tabular numerals where digits change.** `PriceDisplay.tsx:93` and `:97` apply `tabular-nums` to the amount, and `checkout.tsx:268` applies it to the live remaining-codes chip. Prices sit in a row across the three cards, not a column, so no vertical alignment case was found that lacks it.
- **`MacOnlyConfirm` does not trap a legitimate buyer.** It is a radix `AlertDialog` (`MacOnlyConfirm.tsx:27-73`), so focus trap, Escape dismissal and focus restore come from the primitive. It offers both "Not now" (`AlertDialog.Cancel`) and "Download anyway" (`AlertDialog.Action`). It gates only `/download/latest`, never a purchase: both buy CTAs are plain `<Link to="/checkout">` with no platform check, and `/checkout` shows only the non-blocking `NotOnMacBanner`. A non-Mac buyer can complete a purchase.
- **The Polar failure state names a way to recover.** `PolarInlineCheckout.tsx:170-209` renders `role="alert"` with a title, a plain-language body, a labelled reference chip and two actions: Try again and a prefilled Email us `mailto`. No HIGH escalation is triggered by the error state.
- **Reduced motion on the surface's own CSS.** `src/styles.css` carries a guard for `polar-skeleton` (`:2067`), `redeem-bar-shimmer` (`:1359`), `pricing-sparkle-shimmer-shell` (`:1324`), `[data-reveal]` (`:2335`) and `scroll-behavior` (`:441`). The two gaps are the JS `scrollIntoView` and Tailwind's `animate-spin`, both reported above.
- **No `transition: all` and no hardcoded hex.** `grep` over the five in-scope components returns nothing for `transition-all`, `transition: all` and six-digit hex. Every animated rule names its properties.
- **Contrast computed from declared tokens.** sRGB and OkLab conversion in `python3` from `src/styles.css` values. Light `.paper-card` resolves to `#fbf4ea` at the gradient top and `#faf3e8` at the bottom. `--sumi-soft` 8.6:1, `--sumi-soft/90` 6.6:1, `--hinomaru-ink/80` 4.75:1, `--nezumi` 3.36:1. Dark theme: `--nezumi` 6.7:1, `--matcha` 5.8:1, `--hinomaru-ink/80` 5.5:1.
- **React child crash reproduced.** `node` with the repo's own `react` and `react-dom/server`, rendering `React.createElement('li', null, en.pricing.support.items[3])`. Output: `THREW: Objects are not valid as a React child (found: object with keys {title, body}). If you meant to render a collection of children, use an array instead.`

### Not verified

These need the rendered page. Exact checks for the orchestrator:

1. **What `/checkout?tier=support` actually shows.** `src/routes/__root.tsx:391` registers `errorComponent: RouteErrorBoundary`, so the throw should surface as the root error screen rather than a blank page. Load `/checkout?tier=support`, then click the Yearly Patron tab from `/checkout?tier=lifetime`, and record which of the two renders.
2. **`--matcha` at 11.7px.** `#6f7a3a` on `.paper-card` computes to 4.21:1, just under 4.5:1, for the signup success line at `Pricing.tsx:798`. The card `::before` fiber overlay (`styles.css:896-903`, opacity 0.35) shifts the background slightly. Measure the rendered pair before treating it as a failure.
3. **Focus indicator visibility.** Tab through the pricing cards and `/checkout` in light mode and confirm whether the 2.47:1 ring and the 1.69:1 input ring are perceivable on screen, and check forced-colors mode.
4. **Tier toggle at 320px.** `checkout.tsx:200` is `inline-flex w-full` with two `flex-1` tabs. "Lifetime · one payment" at 13px with `px-4` and a 14px icon may wrap or clip. Check 320px and 200% zoom.
5. **Pricing card at 320px.** `Pricing.tsx:203` uses `px-7` (56px total) and the price is `text-[2.25rem]`. Check that the price row, the `MacScopeBadge` and the "Anytime" tag do not overflow.
6. **Announcement volume from the price live regions.** `Pricing.tsx:328` and `:430` are two `aria-live="polite" aria-atomic="true"` regions that can update up to three times on load (SSR value, locale guess, live Polar value). Confirm with a screen reader that this does not read as repeated interruption.
7. **`MacOnlyConfirm` enter animation under reduced motion.** `MacOnlyConfirm.tsx:30` and `:33` use `data-[state=open]:animate-in ... zoom-in-95` from `tw-animate-css`, which has no reduced-motion block. The same classes come from `src/components/ui/dialog.tsx:44` and `:66`, which is out of scope, so the cause is the shared primitive. Confirm whether the dialog still zooms with Reduce Motion on; if it does, the fix belongs in `ui/dialog.tsx`.
8. **Discount count freshness.** `use-discount-availability.ts:23` caches at module scope with no TTL and the server caches for 5 minutes, so "N codes left" can be up to 5 minutes plus the session length stale. Confirm the number is not visibly wrong across a long session.

## Verdict

`Block`.

Four `HIGH` findings remain. The first is the one that matters: `/checkout?tier=support` throws during render because `checkout.tsx:383-386` casts `{ title, body }[]` to `string[]` and renders the object. The Yearly Patron purchase cannot be completed. Fix that before anything else on this list.
